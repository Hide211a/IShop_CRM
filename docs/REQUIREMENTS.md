# Система управління товарними запасами — «iShop Рівне»

## Тема диплому

Розробка системи управління товарними запасами магазину мобільної техніки **iShop Рівне** (м. Рівне).

## Призначення

Внутрішній веб-застосунок для працівників магазину мобільної техніки **iShop Рівне**: облік надходжень, витрат, інвентаризації, контроль залишків і звітність.

## Ролі користувачів

| Роль | Код | Можливості |
|------|-----|------------|
| Адміністратор | `ADMIN` | Користувачі, довідники (категорії, бренди, постачальники, товари) |
| Менеджер | `MANAGER` | Документи руху (надходження, витрата, інвентаризація, резерв), залишки |
| Директор | `DIRECTOR` | Dashboard, звіти (перегляд, експорт) |

## Функціональні вимоги

### Довідники (ADMIN)
- CRUD категорій, брендів, постачальників, товарів
- Управління користувачами та ролями

### Облік запасів (MANAGER)
- Перегляд поточних залишків, пошук і фільтри
- Документ «Надходження» — збільшення залишку
- Документ «Витрата» — продаж / списання
- Документ «Інвентаризація» — коригування до фактичної кількості
- Документ «Резерв» — резервування під покупця (внутрішній процес)
- Проведення документів з автоматичним оновленням залишків

### Звітність (DIRECTOR)
- Dashboard: KPI, низький залишок, останні операції
- Звіт залишків
- Звіт руху товарів за період
- Товари нижче мінімального залишку

### Загальні
- Авторизація JWT
- Role-based доступ до маршрутів і API
- Українська мова інтерфейсу

## Нефункціональні вимоги

- Frontend: React 18, TypeScript, Vite, MUI
- Backend: Node.js, Express, TypeScript, Prisma
- БД: SQLite (локальний файл, без Docker)
- Валідація: недостатній залишок при витраті блокується на сервері
